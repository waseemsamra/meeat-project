# **App Name**: PrimeCuts Hub

## Core Features:

- Product Browsing & Filtering: Allows users to browse beef and lamb products, filtering by category, cut, weight, and grade.
- Secure Checkout: Handles the checkout process, including address forms, shipping options, and secure payment via Stripe.
- Admin Dashboard: Provides an overview of key metrics like total sales, recent orders, and low stock alerts.
- Product Management: Enables admins to create, read, update, and delete product listings with rich text descriptions and multiple image uploads.
- User Management: Allows admins to view, filter, and edit user details and roles.
- Order Management: Provides tools to view and update order details, including fulfillment status and payment information.
- AI-Powered Product Description: Generates engaging and informative product descriptions using a generative AI tool, which can be customized by the admin.

## Style Guidelines:

- Primary color: Rich earthy brown (#A67B5B) evoking natural, high-quality meat products.
- Background color: Soft beige (#F2EBD3) to create a clean and inviting canvas.
- Accent color: Deep red-brown (#803F28) for calls to action and important information, providing contrast.
- Headline font: 'Playfair', a modern serif font that conveys elegance and quality. Body font: 'PT Sans' a classic sans-serif which will ensure comfortable reading.
- Use clear and simple line icons to represent different cuts of meat and product categories.
- Employ a grid-based layout with plenty of white space to create a clean, organized, and trustworthy shopping experience.
- Use subtle animations on hover effects and transitions to provide feedback and enhance user engagement.
